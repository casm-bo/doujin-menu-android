# doujin-menu-android

[![GitHub latest release](https://img.shields.io/github/v/release/casm-bo/doujin-menu-android)](https://github.com/casm-bo/doujin-menu-android/releases/latest)
[![GitHub Downloads](https://img.shields.io/github/downloads/casm-bo/doujin-menu-android/total)](https://github.com/casm-bo/doujin-menu-android/releases/latest)

[doujin-menu 데스크톱 앱](https://github.com/casm-bo/doujin-menu-V2)과 연동하거나 단독으로 사용할 수 있는 Android 앱입니다. Hitomi 검색과 기기 다운로드·로컬 라이브러리는 PC 연결 없이 사용하며, PC 다운로드 큐 및 라이브러리 동기화에는 페어링이 필요합니다.

## 주요 기능

- **데스크톱 연결**
  - Companion Server 연결 확인 및 6자리 코드 페어링
  - 여러 데스크톱 저장·선택 및 연결 상태 표시
  - 장치 토큰과 데스크톱 정보를 Android Keystore 기반 AES-GCM으로 암호화 저장
- **Hitomi 검색**
  - PC 연결 없이 Hitomi 리소스에 직접 접근해 검색·상세·온라인 페이지 조회
  - 검색어·언어·작가·태그 필터, 자동 완성 및 검색 즐겨찾기
  - 썸네일·제목·작가·태그·페이지 수를 표시하는 갤러리 카드
  - 30개 단위 페이지네이션과 목록 끝 자동 무한 스크롤
  - 갤러리 상세 조회, 작가·태그 클릭 검색 및 다운로드 요청
- **라이브러리 관리 및 동기화**
  - Android 로컬 폴더와 ZIP/CBZ, 데스크톱 라이브러리 통합 조회
  - `info.txt` 메타데이터 파싱, 검색·정렬·필터, 그리드·목록 보기
  - 즐겨찾기·읽음·숨김·진행률과 사용자 지정 제목 동기화
  - 시리즈 생성·편집·정렬·병합 및 여러 항목 일괄 관리
  - Android 로컬 작품을 CBZ로 묶어 데스크톱에 동기화
- **통합 리더**
  - 로컬 및 원격 작품 전체화면 열람, 마지막 페이지 복원과 다음 작품 이동
  - 좌→우·우→좌 방향, 화면·너비 맞춤, 스와이프·탭 페이지 이동
  - 두 번 탭 확대·이동, 썸네일 탐색, 페이지 번호 및 화면 꺼짐 방지
  - 사용자 지정 9분할 탭 영역
- **다운로드 관리**
  - PC 미연결 시 기기에 대기 요청만 저장하고 자동 다운로드하지 않음
  - 명시적으로 로컬 다운로드를 선택하면 지정 폴더에 CBZ 저장 후 라이브러리에 표시
  - 일시정지·재개, 중단된 페이지 재사용, 미완료 파일의 라이브러리 노출 방지
  - 다음 수동 동기화 때 대기 요청을 PC 큐로 전달하고 요청 ID로 재전송 중복 방지
  - 데스크톱 다운로드 큐의 진행률·속도·오류 확인
  - 일시정지·재개·재시도·취소 및 완료 항목 정리
- **반응형 UI**
  - 휴대폰 하단 내비게이션과 넓은 화면 Navigation Rail
  - 시스템 설정을 따르는 라이트·다크 테마

## 개발 환경

- Android Studio Quail 2 이상 권장
- JDK 17
- Android SDK 37
- Android Gradle Plugin 9.3.0
- Gradle 9.5.0
- Kotlin/Compose Compiler 2.3.21
- Jetpack Compose BOM 2026.06.00
- 최소 Android API 26

Android Studio에서 저장소 루트를 열고 SDK 37을 설치한 뒤 Gradle Sync를 실행합니다.

```powershell
.\gradlew.bat test
.\gradlew.bat assembleDebug
```

## PC 없이 사용하기

1. 검색 탭에서 검색어·필터를 입력합니다. 새 검색과 이미지 다운로드에는 인터넷 연결이 필요합니다.
2. PC 미연결 상태에서 작품 상세의 **다운로드하기**를 누르면 **PC 동기화 대기**에 추가됩니다. 앱을 닫아도 유지됩니다.
3. 기기에 저장하려면 다운로드 탭의 **폴더 선택**으로 저장 위치를 지정하고, 해당 항목의 **로컬 다운로드에 추가**를 누릅니다.
4. 완료된 CBZ는 기존 라이브러리와 리더에서 열 수 있습니다. 선택한 저장 폴더는 라이브러리 경로에도 등록됩니다.
5. 기기에 저장하지 않은 대기 항목은 **PC와 동기화** 또는 라이브러리의 동기화 버튼으로 PC 큐에 전달합니다. 단순 재연결만으로 전송하지 않습니다.

PC 연결 중 새 다운로드 요청은 기존처럼 PC 큐로 전송합니다. 로컬 다운로드를 선택한 항목은 PC 다운로드 요청에서 제외됩니다. 로컬 파일 자체를 PC로 업로드하는 기존 라이브러리 동기화는 별도입니다.

중단된 기기 다운로드는 **기기 다운로드 재개**를 눌러 계속합니다. 이미 받은 페이지를 재사용합니다. 완료 항목의 **기록 정리**는 저장된 작품 파일을 삭제하지 않습니다. 다운로드에는 이미지와 CBZ를 임시 보관할 추가 공간이 필요합니다.

PC 대기 요청은 추가 당시 선택된 PC에 귀속됩니다. PC를 등록하지 않은 상태에서 추가한 요청은 첫 동기화 대상 PC에 귀속됩니다. 전송 여부가 불명확한 요청은 같은 PC와 다시 동기화해 결과를 확인합니다.

**대기 요청 동기화에는 데스크톱의 요청 ID 지원 변경도 필요합니다.** Companion Server의 `/v1/status` 응답이 `downloadRequestIds: true`를 제공해야 합니다. 이전 서버에서는 대기 목록을 유지하고 업데이트 안내를 표시합니다.

## 연결 방법

1. 데스크톱 앱의 `설정 → 모바일 연동`에서 Companion Server를 켭니다.
2. Android 장치와 데스크톱을 같은 사설 네트워크에 연결합니다.
3. 앱에 데스크톱 IP와 포트(기본값 `47831`)를 입력하고 상태를 확인합니다.
4. 데스크톱에서 6자리 코드를 생성해 Android 앱에 입력합니다.
5. 페어링된 데스크톱을 선택한 뒤 다운로드 탭의 **PC와 동기화** 또는 라이브러리 동기화를 실행합니다.

Companion API 1차 버전이 로컬 HTTP를 사용하므로 현재 앱은 cleartext 트래픽을 허용합니다. TLS 또는 요청 서명을 도입할 때 네트워크 보안 설정도 함께 제한해야 합니다.


## 검증

기본 검증: `./gradlew.bat testDebugUnitTest lintDebug assembleDebug`.
실제 Hitomi 검색·페이지 주소 조회까지 확인하려면 `HITOMI_LIVE_TEST=1` 환경변수를 지정하고 `DirectHitomiTest`를 실행합니다.

실기기 확인 항목:

- PC 미등록 상태에서 검색·상세·온라인 리더 사용.
- PC 미연결 상태에서 다운로드 추가 후 앱 종료·재실행 시 대기 유지.
- 저장 폴더 권한 허용 후 명시적으로 로컬 다운로드 시작, 화면을 끈 상태의 실행, 일시정지·재개.
- 저장 공간 부족·폴더 권한 회수 시 오류 표시 및 미완료 작품 제외.
- PC 동기화 재시도 시 중복 등록 없음, 로컬 다운로드 항목 제외.
